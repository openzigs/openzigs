# OpenZigs UI

This folder contains the Next.js control panel used to manage tool toggles, approvals, and audit activity.

## Env vars

- `NEXT_PUBLIC_OPENZIGS_API_BASE` (default: http://localhost:3001)
- `NEXT_PUBLIC_OPENZIGS_SOCKET_URL` (default: same as API base)
- `NEXT_PUBLIC_OPENZIGS_TOKEN` (local auth token)
