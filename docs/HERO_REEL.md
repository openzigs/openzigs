# OpenZigs Hero Reel — Inspiration Script

> **Format:** 60–90 second cinematic hero reel for openzigs.com landing page
> **Tone:** Bold, confident, technically grounded — think Apple product video meets open-source manifesto
> **Pacing:** Fast cuts, punchy text overlays, real product footage interleaved with motion graphics

---

## ACT I — THE NAME (0:00–0:18)

### Visual: Dark screen. A single cursor blinks. Then text types itself out:

> **"Open"** — for Open Standards.

**CUT TO:** Montage of open-weight model logos (Flux, Demucs, LTX-Video, Kokoro, ACE-Step) snapping into a modular grid. JSON schemas flying into place. Zod validation badges lighting up green.

> We believe the future of AI media generation shouldn't be locked behind walled gardens. OpenZigs is built on a foundation of open standards, seamless integrations, and modularity. From open-weight models to standard JSON schemas for tool-calling — the platform is extensible, transparent, and developer-friendly.

**BEAT. Text dissolves.**

> **"Zigs"** — for Non-Linear Intelligence.

**CUT TO:** A straight-line pipeline diagram. It hits a red error. Shatters. The pieces rearrange themselves — zigging and zagging — into a branching, self-healing DAG that routes around the failure and lights up green at the finish.

> Traditional pipelines take a straight line. Step A, then Step B. If something goes wrong, the system crashes. OpenZigs is different. Powered by an autonomous agentic loop, our AI doesn't take a straight line. It hits an error — it zigs. Encounters a missing file — it zags. It evaluates the obstacle, selects a different tool, and charts a new multi-step path to solve your problem.

## ACT III — THE ARCHITECTURE (0:48–1:05)

### Visual: Blueprint-style wireframe of the system unfolds. Each block lights up as it's named.

**[TEXT: "Agents That Orchestrate Agents."]**

`spawn-agent` fires off a background researcher. `orchestrate-agents` launches 5 parallel writers. DAG task trees fan out. Results converge. A pipeline post-action publishes the output — no LLM call needed.

---

**[TEXT: "Human in the Loop. When It Matters."]**

Approval queue visualization: a high-risk shell command pauses mid-execution. A notification pings on Telegram. The user taps "Approve." The agent resumes. Trust by design.

---

**[TEXT: "Sentinel Watches. Always."]**

The Sentinel SRE monitor runs hourly health checks. Detects a failure pattern. Fires a critical alert to Discord. Generates a daily digest. The system self-reports before you even notice.

---

**[TEXT: "Local-First. Your Machine. Your Data."]**

SQLite WAL mode. JSONL session logs. Auth tokens at 0600 perms. Docker sidecars for isolation. Config layering with Zod validation. No cloud dependency required.
