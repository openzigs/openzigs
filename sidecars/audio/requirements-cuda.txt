# Audio Sidecar — NVIDIA CUDA dependencies
# Extends base requirements.txt for CUDA/PyTorch on NVIDIA GPUs.
#
# Usage (inside the audio venv, after installing PyTorch with CUDA wheels):
#   pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu121
#   pip install -r requirements-cuda.txt
#
# Platform split:
#   Apple Silicon:  server.py + requirements.txt + requirements-mac.txt  (f5-tts-mlx)
#   NVIDIA CUDA:    server_cuda.py + requirements-cuda.txt               (f5-tts)
